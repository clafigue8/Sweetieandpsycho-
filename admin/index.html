Panel de la tienda

Conecta el panel con el repositorio de GitHub donde vive la tienda. Los cambios se publican como commits y la página se actualiza en 1–2 minutos.

¿Cómo obtengo el token?
  1. En GitHub ve a Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Generate new token. En “Repository access” elige Only select repositories y selecciona el repositorio de la tienda.
  3. En “Permissions → Repository permissions” pon Contents: Read and write.
  4. Copia el token y pégalo aquí. Nunca lo compartas.

Cómo te llegan los pedidos

Cuando un cliente finaliza su carrito, se le abre WhatsApp o su correo con el pedido completo listo para enviarte.

Pedidos a tu correo (botón “Agendar pedido”)

La clienta toca el botón y el pedido te llega al correo (con notificación en tu celular si tienes la app de Gmail). Necesita una clave gratuita de Web3Forms:

  1. Entra a web3forms.com y escribe el correo donde quieres recibir los pedidos.
  2. Te llega un correo con tu Access Key. Cópiala y pégala aquí.

Con 20000, el primer pedido será S&P💗20001, luego 20002… Si el contador no responde, el pedido igual se envía con un código que empieza con “W”.

Sin clave, el botón vuelve a ser “Enviar pedido por WhatsApp”.
